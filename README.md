# Project Overview

This repository contains the weekly cybersecurity internship work focused on identifying vulnerabilities in a web application (OWASP Juice Shop) and implementing security improvements using industry-standard tools and techniques.

The project is divided into three main phases:

---

# Week 1 – Security Assessment

In Week 1, the focus was on analyzing the web application for common vulnerabilities.

### Activities Performed:
- Setup of OWASP Juice Shop application locally
- Basic exploration of application features (login, signup, etc.)
- Testing for vulnerabilities such as:
  - Cross-Site Scripting (XSS)
  - SQL Injection
- OWASP ZAP passive scanning
- Browser developer tools analysis

### Outcome:
Identified low to medium risk security issues and understood how attackers exploit web applications.

---

# Week 2 – Security Implementation

In Week 2, security improvements were implemented based on Week 1 findings.

### Activities Performed:
- Input validation using validator library
- Password hashing using bcrypt
- JWT-based authentication system
- HTTP security hardening using Helmet.js

### Outcome:
Application security was improved by securing authentication, input handling, and HTTP response headers.

---

# Week 3 – Logging & Network Security

In Week 3, focus shifted to monitoring and network-level security analysis.

### Activities Performed:
- Implemented logging using Winston
- Continued use of Helmet for security headers
- Performed network scanning using Nmap
- Analyzed open ports and running services

### Outcome:
Improved visibility of application activity and gained understanding of network exposure and security risks.
